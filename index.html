    How it works

    Checked by a real browser

    A caller site runs in another origin, so whether it can load your network is decided by the browser's CORS rules. A command-line check can only read headers. This page asks the browser itself: if it can read your manifest and network from here, so can other agent sites.

    Validated by the reference runtime

    Network definitions are parsed and validated with the browser runtime's own kernel, the code that will run them. Then 25 checks map each rule of the MVP profile to a file, a result and a fix.

    Read only, nothing sent

    An inspection fetches public files without cookies or credentials. It never runs the inspected site's code or agents, and masks anything that looks like a key.

    Also in your terminal

    The same checks run in CI: node tools/inspect.mjs https://your.site/agents/my_network --strict exits non-zero when a check fails.
